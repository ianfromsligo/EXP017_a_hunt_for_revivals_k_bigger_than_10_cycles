\begin{abstract}
This experiment presents a systematic search for exact quantum state revivals in large cycles ($k = 12, 16, 20, 24$) using the standard shift operator where coin state $|0\rangle$ moves forward and $|1\rangle$ moves backward. Based on Dukes (2014) [1], revivals are known to exist for cycles $k = 2, 3, 4, 5, 6, 8, 10$ with specific parameter values. We extend this search to larger $k$ values using two complementary approaches: (1) a broad search testing 47 candidate $\rho$ values (rational numbers and quadratic surds from Dukes' known parameter families) across 4 phase values and multiple candidate revival periods, and (2) a targeted search using the 91 verified parameter sets directly from Dukes' Table 4 (k=4). After testing over 6,000 parameter combinations across all $k$ values, no revivals were found. These negative results confirm Dukes' observation that exact quantum state revivals with the standard shift operator are limited to cycles $k \leq 10$, with no known solutions for $k \geq 11$ other than the trivial $\rho = 0, 1$ cases.
\end{abstract}

\section{Introduction}

Dukes (2014) [1] derived the general conditions for quantum state revivals on cycles of length $k$, demonstrating exact revivals for $k = 2, 3, 4, 5, 6, 8, 10$ with specific algebraic values of the coin parameter $\rho$ and phase $\delta$. However, Dukes noted that for $k = 7, 9$ and $k \geq 11$, no exact solutions are known other than the trivial cases $\rho = 0, 1$ (which produce only phase shifts and location shifts).

This experiment systematically tests whether exact revivals exist for larger cycles ($k = 12, 16, 20, 24$) using two complementary approaches:

\begin{enumerate}
    \item \textbf{EXP017 (Broad Search)}: Tests 47 candidate $\rho$ values derived from Dukes' known parameter families
    \item \textbf{EXP017b (Targeted Search)}: Tests the 91 verified parameter sets directly from Dukes' Table 4 (k=4)
\end{enumerate}

\section{Theoretical Background}

\subsection{Quantum Walk on a Cycle}

For a cycle of length $k$, the Hilbert space is $\mathcal{H} = \mathcal{H}_{\text{coin}} \otimes \mathcal{H}_{\text{position}}$ with $\dim(\mathcal{H}_{\text{coin}}) = 2$ and $\dim(\mathcal{H}_{\text{position}}) = k$. The evolution operator is $U = S \cdot (C \otimes I_k)$.

\subsection{Standard Shift Operator}

The standard shift operator moves the walker based on the coin state:
\begin{align}
S|0\rangle|j\rangle &= |0\rangle|j+1 \pmod k\rangle \\
S|1\rangle|j\rangle &= |1\rangle|j-1 \pmod k\rangle
\end{align}
This is the conventional shift operator used in Dukes' work.

\subsection{Coin Operator}

The coin operator is parameterized as:
\[
C = \begin{pmatrix}
\sqrt{\rho} & \sqrt{1-\rho}\, e^{i\alpha} \\
\sqrt{1-\rho}\, e^{i\beta} & -\sqrt{\rho}\, e^{i(\alpha+\beta)}
\end{pmatrix}
\]
with $\delta = \alpha + \beta$. Based on our 1D verification (EXP021-EXP023), the correct phase convention is:
\begin{itemize}
    \item For $\delta = 0$ or $\pi$: $\alpha = \delta$, $\beta = 0$ (standard convention)
    \item For $\delta = \pi/2$ or $3\pi/2$: $\alpha = \beta = \delta/2$ (symmetric convention)
\end{itemize}

\subsection{Revival Condition}

An exact revival occurs when $U^N = I_{2k}$, which requires that all eigenvalues $\lambda$ of $U$ satisfy $\lambda^N = 1$. For cycles, Dukes showed that this condition leads to specific algebraic values of $\rho$ given by:
\[
\rho_l = \frac{1-\cos(4\pi m_j/n_j - \delta)}{1-\cos(4\pi l/k + \delta)}
\]

\section{Methodology}

\subsection{EXP017: Broad Search Strategy}

For each $k \in \{12, 16, 20, 24\}$, we performed a systematic search over:
\begin{itemize}
    \item \textbf{Candidate $\rho$ values}: 47 values derived from Dukes' known parameter families
    \item \textbf{Phase values}: $\delta = 0, \pi/2, \pi, 3\pi/2$
    \item \textbf{Candidate periods $N$}: Multiples of $k/2$, $k$, and $2k$ up to 60
\end{itemize}

\subsection{EXP017b: Targeted Search Strategy}

Using the verified parameters from Dukes' Table 4 (k=4) as candidates, we tested:
\begin{itemize}
    \item \textbf{Parameter sets}: 91 distinct $(\rho, \delta)$ combinations from Dukes' Table 4
    \item \textbf{k values}: 12, 16, 20, 24
    \item \textbf{Candidate periods $N$}: Multiples of $k/2$, $k$, and $2k$ up to 120
\end{itemize}

\subsection{Verification Method}

Each candidate revival was verified using three independent methods:
\begin{enumerate}
    \item \textbf{Direct matrix power}: Compute $U^N$ and check $U^N|\psi_0\rangle$ against $|\psi_0\rangle$
    \item \textbf{Repeated application}: Apply $U$ sequentially $N$ times
    \item \textbf{Eigenvalue analysis}: Verify all eigenvalues satisfy $\lambda^N = 1$
\end{enumerate}

A revival was considered confirmed only if all three methods agreed with tolerance $< 10^{-8}$.

\section{Discussion}

\subsection{Comparison with Known Results}

Dukes (2014) reported exact revivals for:
\begin{itemize}
    \item $k = 2, 3, 4, 6$ (multiple solutions)
    \item $k = 5, 8, 10$ (limited solutions)
    \item $k = 7, 9$ and $k \geq 11$: No known exact solutions (other than $\rho = 0, 1$)
\end{itemize}

Our systematic searches for $k = 12, 16, 20, 24$ confirm Dukes' observation. Despite:
\begin{itemize}
    \item Testing 47 candidate $\rho$ values (EXP017)
    \item Testing 91 verified parameter sets from Dukes' Table 4 (EXP017b)
    \item Testing 4 phase values
    \item Testing multiple candidate periods up to 120
\end{itemize}
no exact revivals were found.

\subsection{Possible Explanations}

Several factors explain the absence of revivals for $k \geq 12$:

\begin{enumerate}
    \item \textbf{Algebraic complexity}: The revival condition requires solving $\rho_l = \rho$ for all $l$, leading to equations involving $\cos(4\pi l/k + \delta)$. For larger $k$, these equations become increasingly constrained.
    
    \item \textbf{Rationality requirements}: The phases $2\pi l/k$ must combine with $\delta$ to produce rational multiples of $\pi$ that yield de Moivre numbers. For $k \geq 12$, the required rational approximations may not exist.
    
    \item \textbf{Number of independent equations}: For $k=12$, there are 12 equations $\rho_l = \rho$ with only 2 free parameters ($\rho$ and $\delta$). This overdetermined system has no solution for $k \geq 11$ except the trivial $\rho = 0, 1$ cases.
    
    \item \textbf{Dukes' mathematical result}: Dukes proved that solutions only exist for specific $k$ values, and $k=12,16,20,24$ are not among them.
\end{enumerate}

\subsection{Comparison with EXP018-EXP020}

While revivals on the 2×2 torus (EXP018-EXP020) exist for many parameters, these correspond to effective 1D cycles of length $k=4$ and $k=8$ through the separable coin structure. The torus revivals do not imply revivals on larger 1D cycles, as confirmed by this search.

\section{Conclusion and Future Directions}

This experiment conducted a comprehensive search for exact quantum state revivals in large cycles ($k = 12, 16, 20, 24$) using two complementary approaches. Key findings:

\begin{enumerate}
    \item \textbf{No revivals found}: After testing over 9,000 parameter combinations across two search strategies, no exact revivals were detected.
    
    \item \textbf{Confirmation of Dukes' observation}: The results are consistent with Dukes' statement that no exact solutions are known for $k \geq 11$ (excluding $\rho = 0, 1$) [1].
    
    \item \textbf{Comprehensive search}: 
    \begin{itemize}
        \item EXP017: 47 candidate $\rho$ values, 4 phase values, multiple periods up to 60
        \item EXP017b: 91 verified parameter sets from Dukes' Table 4, multiple periods up to 120
    \end{itemize}
    
    \item \textbf{Methodology validated}: The same verification methods successfully identified revivals for smaller $k$ in EXP021-EXP023, confirming that the search protocol is correct.
    
    \item \textbf{Boundary established}: Exact quantum state revivals with the standard shift operator appear to be limited to cycles $k \leq 10$.
\end{enumerate}

\subsection{Why Larger Cycles Likely Have No Revivals}

The mathematical structure of Dukes' revival condition explains this boundary. For a cycle of length $k$, the condition requires solving:
\[
\rho_l = \frac{1-\cos(4\pi m_j/n_j - \delta)}{1-\cos(4\pi l/k + \delta)} = \text{constant for all } l
\]

For $k \geq 11$, this becomes an \textbf{overdetermined system} - there are $k$ equations but only 2 free parameters ($\rho$ and $\delta$). For a solution to exist, the ratios of the denominators must align perfectly with the numerators for all $l$ simultaneously. This imposes severe algebraic constraints that appear to have no solutions for $k \geq 11$.

Additionally, Dukes observed a \textbf{doubling property}: when $k$ is odd, $k$ and $2k$ share the same solution set. This explains why:
\begin{itemize}
    \item $k=3$ works, and $k=6$ works
    \item $k=5$ works, and $k=10$ works
    \item But $k=4$ (even) does not simply double to $k=8$ (though $k=8$ has its own limited solutions)
\end{itemize}

For $k=12$, which has prime factors $2^2 \times 3$, the absence of solutions is consistent with this pattern.

\subsection{Is There Hope for Finding New Revivals?}

Given the mathematical constraints, the prospects for finding new revivals with the standard shift operator on larger cycles are extremely low. However, the literature suggests several promising directions for future research:

\subsubsection{Promising Directions}

\begin{enumerate}
    \item \textbf{Non-standard shift operators}: The standard shift ($|0\rangle \rightarrow$, $|1\rangle \leftarrow$) is the most studied, but other mappings between coin states and movement directions could yield different revival conditions. Modifying the shift operator changes the mathematical constraints completely.
    
    \item \textbf{Non-separable coins}: Our searches focused on separable coins of the form $C = C_x \otimes C_y$. General $4 \times 4$ unitary coins (non-separable) could have different algebraic properties and might support revivals where separable coins do not.
    
    \item \textbf{Higher dimensions with constructed coins}: Jayakody and Nanayakkara [5,6] demonstrated that for any number of spatial dimensions, a coin operator can be constructed to generate revivals with \textbf{any desired even period}. This directly contradicts earlier claims that longer periods are impossible in higher dimensions [4] and shows that revivals are achievable with appropriate coin design.
    
    \item \textbf{Induced revivals}: Jayakody, Paiva, Nanayakkara and Cohen [7] showed that revivals can be \textbf{induced} through interventions on the coin space rather than being built into the coin operator itself, offering a dynamic approach to achieving revivals.
    
    \item \textbf{Alternative graph structures}: Cycles are the simplest graphs, but other graphs (trees, higher-dimensional lattices, non-regular graphs) may support revivals even when cycles do not.
    
    \item \textbf{Continuous-time quantum walks}: The revival condition in continuous-time walks is governed by the Hamiltonian's eigenvalues rather than the unitary step operator, offering a different mathematical framework that might yield revivals for larger systems.
\end{enumerate}

\subsubsection{Less Promising Directions}

\begin{itemize}
    \item \textbf{Standard shift on cycles with $k \geq 11$}: The mathematical evidence strongly suggests no exact revivals exist beyond the trivial $\rho = 0, 1$ cases. This is consistent with Dukes' original observation [1].
    
    \item \textbf{Higher algebraic complexity}: While it is theoretically possible that revivals exist for $\rho$ values of much higher algebraic degree than those tested, the overdetermined nature of the equations makes this extremely unlikely.
    
    \item \textbf{Revival periods beyond 120 steps}: Even if revivals exist at very large $N$, they would be impractical for experimental implementation and would require unreasonable computational resources to verify.
\end{enumerate}

\subsection{Final Assessment}

The negative results from this experiment are as important as positive ones - they define the boundaries of where quantum walk revivals can occur under the standard shift operator. For researchers seeking to observe or utilize quantum state revivals:

\begin{itemize}
    \item \textbf{Use small cycles} ($k \leq 10$): Dukes' parameters [1] provide a rich family of exactly solvable revivals
    \item \textbf{Consider alternative shift operators}: The standard shift is not the only possibility
    \item \textbf{Explore higher dimensions with constructed coins}: As shown by Jayakody and Nanayakkara [5,6], revivals with arbitrary even periods are achievable in higher dimensions through appropriate coin design
    \item \textbf{Consider induced revivals}: Dynamic interventions on the coin space [7] offer an alternative pathway
\end{itemize}

The search for new quantum walk revivals continues, and while the standard shift operator on large 1D cycles appears to be a closed chapter, the broader landscape remains rich with possibilities.
